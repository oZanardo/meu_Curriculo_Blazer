## 🚀 Guia de Execução

Siga os passos abaixo para executar o projeto localmente via terminal:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/meuCurriculo.git

# Acesse a pasta do projeto
cd meuCurriculo

# Restaure as dependências
dotnet restore

# Execute a aplicação
dotnet run
```

Após executar, acesse no navegador:


```
http://localhost:5000
```
